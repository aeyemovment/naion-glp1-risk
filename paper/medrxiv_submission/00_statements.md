# Required statements

## Ethics / IRB
This study used only data reported in published, peer-reviewed articles and publicly available pharmacovigilance summaries, together with computationally generated synthetic records. No individual-level health information was accessed and no human participants were recruited; institutional review board approval and informed consent were therefore not required.

## Clinical trial registration
Not applicable (no clinical trial).

## Funding
This work received no specific funding.

## Competing interests
K. E. Green is the founder of NeuroAgent AI, Inc. and HazyEyes AI. The author declares no other competing interests.

## Data availability
All extracted data (with PMID and evidence quotation for every value), the reconstructed count-weighted patient-level data, synthetic digital-twin datasets, analysis code and result files are available at https://github.com/aeyemovment/naion-glp1-risk (release v1.0.0). A research-only calculator is at https://naion-glp1-calculator.vercel.app. Source publications are listed by PMID in the extraction files.

## Code availability
Analysis code (Python) and model weights: https://github.com/aeyemovment/naion-glp1-risk (MIT licence; data CC BY 4.0).

## Use of AI tools

Every extracted value carries its source PMID and a supporting quotation. The author reviewed and takes responsibility for all content. AI tools are not authors.
