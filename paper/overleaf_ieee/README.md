# Overleaf project - IEEE (IEEEtran) manuscript

1. Overleaf > New Project > Upload Project > select `naion_glp1_ieee_overleaf.zip`.
2. Compiler is XeLaTeX (set by `latexmkrc`; check Menu > Compiler). Main document: `main.tex`. IEEEtran.cls/.bst are built into Overleaf.
3. References: `references.bib` (BibTeX, IEEEtran style; >6 authors shown as et al.). Figures: `figures/`.

Generated by `src/make_ieee.py`; edits made in Overleaf do not flow back into the generator.
